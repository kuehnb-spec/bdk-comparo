# BDK Comparo

A macOS folder comparison and sync utility built with SwiftUI.

## Features
- Compare two folders side-by-side
- Identify files that are only in one folder
- Detect modified files
- Sync files between folders

## Building

Requires macOS and Swift. Run:

```bash
./build.sh
```

Then run the app:

```bash
./BDKComparo
```
